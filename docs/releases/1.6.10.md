**v1.6.10 — A blocked DSH profile write now says what happened**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness (website https://dsh-plugin.org). This release makes one more failure explain itself.

**What's new**

- When DSH times out waiting for the file lock while writing the plugin list — usually because another DSH process or install task is writing the same profile — the install now names that as the cause and tells you what to do: close the other dsh windows or running commands and retry.

- That failure no longer shows up as "cause unclassified", and no longer asks you to file an issue: it is not a plugin problem.

Thanks to @3chet for the report.

**Install**

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
