DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.0.3 makes failure dialogs readable when the host rejects a plugin. Website: https://dsh-plugin.org

## What's changed

- Failure dialogs now expand the minified `peerDependencies` JSON from host version-gate messages into one dependency per line, and copying the log keeps that readable form.
- The same formatting applies to the copy action in the notification center.
- Classification and the content of reported issues are unchanged.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
