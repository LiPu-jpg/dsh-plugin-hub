**v1.6.8 — Make install failures explain themselves**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release makes an install failure show its real cause and be handled correctly, instead of being reported as unknown or blocking a plugin that is already installed.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Failures keep a readable cause** — When an install fails and the underlying error is not available, the installer now retrieves the full failure detail, so the cause is shown and classified correctly instead of being reported as unknown.
- **Installing an already-installed plugin no longer errors** — Clicking "Install" on a plugin that is already present no longer fails with `already installed`; the install now runs as an update and completes normally.
- **Clearer state prompts** — The installer's own state messages (not installed / already removed / already queued) are no longer treated as an unknown fault that points you at filing a GitHub issue; they now give an actionable "refresh and retry" hint.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app.
