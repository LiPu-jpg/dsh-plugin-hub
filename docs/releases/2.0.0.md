**v2.0.0 — 破坏性变更：插件商城只展示能用 NPM 一键安装的插件**

DSH Plugin Hub 是 DeepSeek Harness 的社区插件市场插件（官网 https://dsh-plugin.org）。本次为破坏性变更：升级后源码安装入口消失，目录只展示已发布 NPM 包的插件。

**更新内容**

- 插件商城只展示能用 NPM 一键安装的插件：目录从 14000+ 条收敛到 4597 条；没有发布 NPM 包的仓库仍会被收录（可用源码安装命令安装），但不再出现在商城列表与详情页。
- 移除源码安装与 DSH 命令两条安装通道：自定义安装现在只接受 NPM 包名；想从 GitHub 源码安装，请直接在终端用 DSH 自己的命令安装。客户端与服务端相关代码、文案与文档一并清理。
- 更新提示加了 24 小时门禁：pnpm 会拒绝发布不满 24 小时的版本（dsh profile 默认 minimumReleaseAge=1440），此时点更新只会装回上一个版本；现在检测到目标版本发布不满 24 小时时不提示更新，等超时后再出现，不再出现「点了更新却没更新」。
- 失败归属调整：「插件依赖的原生模块构建脚本被 pnpm 拦截」这类失败，现在引导到插件作者仓库反馈（安装器已自动放行并重试过一次，仍失败说明作者应提供预构建产物），并保留一条「可能是市场误判」的反馈入口给我们。
- 失败分类补齐：网络类失败现在能识别 undici 的符号错误码（如 `UND_ERR_SOCKET`）；宿主只回显一行摘要、日志读不回来时，失败记录里会明确标出「日志未能读回」，便于排查。
- 注释与文档统一中文，并清理了源码安装通道遗留的过时说明。

**安装方式**

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
