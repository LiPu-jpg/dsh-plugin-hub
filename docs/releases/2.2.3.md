DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the in-app updater that could stop offering updates entirely. Website: <https://dsh-plugin.org>

## What's fixed

- **The update entry no longer disappears.** The version endpoint publishes the last ten releases so the hub can fall back to an older release that has already passed pnpm's 24.5-hour supply-chain hold. The client rebuilt that payload with only three fields and dropped the release list, so only the newest release was ever considered — while it was inside the hold, the dialog stayed at "not yet" with no way to update at all. This regression was introduced in v2.1.0.
- **Malformed entries in that list are ignored** instead of reaching the version comparison.

If you are stuck on an older version, update from a terminal:

```bash
dsh plugin --profile <your-profile> add dsh-plugin@2.2.3
```

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
