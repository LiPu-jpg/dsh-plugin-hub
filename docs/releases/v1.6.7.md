**v1.6.7 — Fix skill-only bundles being blocked on the git channel**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the install guard wrongly blocking skill-only bundles — plugins that declare `dsh.bundle.patch` and no JavaScript entry — on the git channel, and misreporting them to their authors.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Skill-only bundles install correctly from the git channel** — A plugin that declares only `dsh.bundle.patch` (no `main`/`exports`) is a complete distribution and is no longer blocked. The guard now checks only the files a manifest actually declares (its entry and its bundle patches), and correctly catches a missing declared patch. Thanks to @SU-AN-coder ([#182](https://github.com/dshplugin/dsh-plugin-hub/pull/182)).

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app.
