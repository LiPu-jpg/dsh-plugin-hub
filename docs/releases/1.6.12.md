**v1.6.12 — Failure reports follow the action that failed, and an unlaunchable host is named**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness (website https://dsh-plugin.org). This release makes failure reports say what actually happened.

**What's new**

- Removing a plugin is no longer reported as a failed install: issue titles and bodies, the failure dialog and its hints all take their wording from the action that actually ran (install / update / removal).

- A failure caused by DSH not being able to start itself is now named as such, with an actionable hint — restart DSH, and reinstall it if it keeps happening — instead of "cause unclassified". It no longer asks you to file an issue, because it is not a plugin problem.

- Update failures show "Update failed" in the failure dialog instead of being filed under install / removal.

**Install**

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
