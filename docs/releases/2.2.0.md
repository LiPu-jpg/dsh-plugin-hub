DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release makes the guidance after a failed install or removal precise: when the failure is something you can fix on your machine, you get the exact steps — instead of being sent to the plugin author or to our issue tracker. Website: <https://dsh-plugin.org>

## What's new

- **Plugins that need a newer DSH are called out.** After a failed install, the installer checks the plugin's declared minimum DSH version and tells you to upgrade DSH first, instead of leaving it as an unknown error.
- **Profiles whose dependency directory was built with a different `virtual-store-dir-max-length` are detected.** The dialog gives the exact steps to rebuild that directory, so removals no longer dead-end.
- **Dangling local dependencies are named.** When the profile keeps a `link:` / `file:` entry whose target directory no longer exists, the missing directory is shown with the fix.
- **Desktop-managed profiles are explained.** You are told to install from inside the app, and the installer no longer misses the app's bundled CLI bootstrap on desktop; if that detection itself fails, a feedback link is offered.
- **Local-environment failures stay local.** Failures that cannot be pinned down but carry local-environment signals now show a self-check list with a direct diagnostics entry instead of asking you to file an issue. Genuinely unidentifiable failures are still reported to us.
- **Better failure reports.** The installer's own diagnostic lines (log recovery result, "host printed nothing") are no longer filtered out of the issue body, and the issue template no longer asks for a `hub.log` that contains no pnpm output — it points to copying the full log from the Hub notifications.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
