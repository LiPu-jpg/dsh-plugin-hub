DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness — browse, search and install 10,000+ curated community plugins without leaving the app. Website: <https://dsh-plugin.org>

This release tightens failure diagnosis and update detection: when something fails on your machine, the hub now tells you what to do instead of pointing you at the issue tracker — and the "update available" badge only appears when npm actually has something newer to install.

## What's new

- **Local failures come with steps.** A profile whose pnpm metadata no longer matches the local pnpm (outdated lockfile, missing manifest, `packageManager` mismatch, unapplied patch) is now identified and explained, instead of being reported as an unknown bug.
- **More environment causes recognized.** A plugin that needs a newer Node / pnpm, registry 5xx responses and a corrupted pnpm store are classified as local causes with the matching fix.
- **No more updates that cannot be installed.** The "update available" badge is verified against the npm registry, so a GitHub-only release that was never published to npm no longer shows an update that can never be applied.
- **The supply-chain gate follows the version that gets installed**, so the badge no longer shows up before it can actually be acted on.
- **Installed versions survive a page reload mid-install** — an undetermined version no longer wipes the record that update detection relies on.
- **Certificate trust failures no longer retry every mirror**, which used to double the wait and bury the real cause; the cancel button and the GitHub tooltip are now localized in Chinese too.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
