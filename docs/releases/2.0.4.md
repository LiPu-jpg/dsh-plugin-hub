DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.0.4 makes failure attribution more accurate, so users see the right next step instead of a generic error. Website: https://dsh-plugin.org

## What's changed

- Client request timeouts are now classified as network issues with connectivity guidance, instead of an unclassified failure.
- New "native build toolchain is missing" failure: when a plugin needs a locally compiled native module but no C/C++ compiler is available, the dialog gives platform-specific install steps instead of blaming the plugin author.
- Neither case asks users to file an issue.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
