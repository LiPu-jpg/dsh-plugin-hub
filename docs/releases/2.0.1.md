DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.0.1 turns every install, update, and uninstall failure into clear guidance: what failed, why, and what to do next. Website: https://dsh-plugin.org

## What's changed

- Failure dialogs now lead with the failure type and a one-line reason, followed by recovery steps.
- When an operation fails, the confirmation/progress dialog closes automatically, leaving the error dialog as the only window.
- Precise hint for plugins that do not support the running DSH version: the exact version is shown, with separate guidance for the author's compatibility list and the desktop app's version allowance.
- Fixed empty log capture on some machines: the real pnpm error is now recovered even after the host finishes the operation.
- The "Plugin details" link now colors only the URL and keeps the source parameter out of the label.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
