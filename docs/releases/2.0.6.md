DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.0.6 fixes how local installs are recognized and turns a missing Git into a clear, actionable message. Website: https://dsh-plugin.org

## What's changed

- Fixed local installs (`file:` / `link:`) being matched with a same-named catalog entry, which made the Installed page show another plugin's details; they are now shown as custom installs of your own.
- Fixed Git-source installs on a machine without Git: the install now stops right away with a "git is missing" message and install instructions instead of a garbled platform error.
- `dsh` and `git` availability is checked before an install starts, so setup problems are reported as actionable messages instead of generic failures.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
