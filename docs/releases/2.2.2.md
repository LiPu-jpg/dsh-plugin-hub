DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This is a hotfix for 2.2.1 — on affected machines the marketplace section could render a blank page. Website: <https://dsh-plugin.org>

## What's fixed

- **The settings page no longer goes blank.** A version-ledger record can exist with only the npm package name right after an install starts, because the version is only known when the task finishes. 2.2.1 compared that missing version directly and the marketplace section crashed with a `TypeError`. A missing version is now treated as "no version signal", and update detection falls back to the repository update time.
- **Dirty ledgers are repaired on read**, and records are always written with every field, so a partially written entry can no longer break the UI.
- **Defensive version comparison**: missing or empty version strings never throw.

If you are on 2.2.1 and the marketplace section is blank, update from a terminal — the in-app update button is unreachable while the section is blank:

```bash
dsh plugin --profile web add dsh-plugin@2.2.2
```

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
