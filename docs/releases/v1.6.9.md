**v1.6.9 — Install failures stop pointing users the wrong way**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release corrects failures whose message did not match the real cause, and stops offering a one-click install for plugins that can only be assembled in a terminal.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Timed-out installs are no longer reported as failures** — When the install command hits the local time limit, the installer re-checks what is already installed: if the plugin really did get installed, the result is now reported as a success instead of a failure (#197).
- **Timeouts are their own category** — A timed-out install now shows an actionable hint (refresh to confirm) instead of pointing you at filing a GitHub issue (#197).
- **Plugins that must be installed from a terminal are marked as such** — Plugins whose install needs a build or a step-by-step assembly in the terminal no longer offer a one-click install; the marketplace shows the command and guides you to the terminal instead (#198, #199).
- **Clearer prompt when a build is blocked** — When a build is blocked by the package manager allowlist, the hint now explains what happened, that the installer already allowed it and retried once, and what to try next.
- **Complete environment details in failure reports** — pnpm / npm versions were missing on Windows and the git version carried a stray prefix; failure reports now show all three correctly.
- **A feedback path for suspected misjudgements** — The plugin-packaging guidance gained a secondary entry point: if you believe the marketplace judged a plugin wrongly, you can report that to the Plugin Hub directly.

Thanks to @lmx270690983-design and @Xred-keep for the reports.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app.
