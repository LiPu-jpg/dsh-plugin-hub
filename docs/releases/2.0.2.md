DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.0.2 makes one-click issue reports carry the actual failure reason instead of only a generic wrapper line. Website: https://dsh-plugin.org

## What's changed

- Host version-gate failures now put the host's real rejection message into the issue body, including the rejected DSH version, instead of only `plugin command failed`.
- Other wrapped failures keep their diagnostic line under the same rule, so reports stay useful even when the host prints a one-line summary.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
