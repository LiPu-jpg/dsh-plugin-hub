DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.0.5 makes the catalog load reliably on slow and proxied networks, and tightens failure diagnosis so the guidance matches the real cause. Website: https://dsh-plugin.org

## What's changed

- Fixed the plugin catalog failing to load on slow or proxied networks: compressed transfers, longer timeouts and deduplicated downloads let the first load finish instead of timing out.
- Added "Force refresh" to the failure state: skip the local cache, download the catalog again, and keep the old cache as a fallback.
- Diagnostics now follows your actual npm registry instead of always probing the official one, and checks the real catalog endpoint — a green result now matches what installing really uses.
- Tarball checksum mismatches caused by GitHub-branch dependencies are now classified clearly, with steps to clear the stale lockfile entry.
- Warns when the marketplace is no longer listed in the profile bundle list after a self-update.
- Section tabs keep their labels on one line and switch to icon-only in narrow panels, so every entry and the notification button stay reachable.
- Thanks to @kevindawn11-hash for the tab-wrapping fix (https://github.com/dshplugin/dsh-plugin-hub/pull/325).

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
