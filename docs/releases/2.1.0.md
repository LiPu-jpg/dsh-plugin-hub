DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. Version 2.1.0 makes update prompts reliable during fast release cycles and makes installs recover from common network and environment problems. Website: https://dsh-plugin.org

## What's changed

- Fixed the hub's own update badge never appearing while releases were published less than 24.5 hours apart: the prompt now targets the newest version that has passed pnpm's release-age gate instead of being reset by every new release.
- Hub self-update installs that exact prompted version instead of `@latest`, so the update lands on the version you were shown.
- Added automatic npm registry fallback: when a public registry times out or is blocked, the installer retries up to three mirrors; custom or intranet registries are never switched. The mirror selected in Settings now applies to real installs too.
- Local `file:` / `link:` installs are no longer matched to a same-named catalog entry, so the Installed page keeps showing your own plugin.
- Install failures are far easier to diagnose: a missing git is reported before the install starts, silent host exits are called out explicitly, and pnpm logs are recovered more reliably on timeouts, relative paths and Chinese (GBK) Windows output.
- Registry 401/403 responses are classified separately with credential and mirror guidance instead of "unknown error".

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
