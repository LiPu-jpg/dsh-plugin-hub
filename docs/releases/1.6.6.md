**v1.6.6 — Fix install failure attribution and restart loop**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes two user-visible problems — install failures were unfairly blamed on plugin authors, and a plugin that failed to load kept prompting a pointless restart — and adds proper support for CLI-only plugins.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Install failures are no longer misattributed to plugin authors** — On a failed install, the hub now points you to the plugin author's repository only when the plugin itself is at fault; network, environment, or unknown causes are directed to the hub repository instead, so authors are no longer blamed for problems outside their control.
- **No more "restart" loop** — When a plugin keeps failing to load even after a restart, the hub no longer keeps showing a "restart" button; it now marks the plugin as inactive, so you don't restart repeatedly for nothing.
- **CLI-only plugins are supported** — Plugins such as cc-safety-net that must be installed via `npx` now show their install command with one-click copy instead of misleading you toward a web install.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app.
